## 1. 打开工具并选择创作模式

首页可进入 **工作台** 或 **玩交互作品**。工作台顶部的 **试玩示例** 可体验四种语言的《雨》。

| 你的目标 | 选择的模式 | 导出结果 |
|---|---|---|
| 制作聊天、动态或论坛截图 | 截图创作 | PNG 单屏、长图或分页图片 |
| 制作可探索的手机故事 | 交互手机 | 独立 HTML 作品文件 |

使用公开网页不需要注册。[点击这里打开编辑器](https://anycolorulike-l.github.io/ficphone/studio.html)，再选择创作模式。

## 2. 制作聊天截图

1. 点击 **截图创作**，选择 KakaoTalk、LINE 或 Messages。
2. 在 **工程基础设置**填写手机主人和联系人备注，在 **会话资料**中设置会话名称、对方头像和群聊成员。
3. 在 **对话脚本**中，每行使用 `名字：消息`。名字与手机主人一致，或写“我”，会显示为本人发送的消息。
4. 在 **工程基础设置 → 画布设置**选择机型，调整时间、电量和语言。**字体与字号**也在工程基础设置中。
5. 点击 **导出单屏 PNG**、**导出长图**或**分页导出**，生成后点击缩略图保存。

脚本格式：

```text
사나：미나야아 뭐 해? 😊
미나：게임 중.
사나：또? 나보다 게임이 더 좋아? ㅋㅋ
미나：🙄
```

想让一张图片或一段语音单独成条，可在 **对话脚本设置**点击 **新增图片消息**或**新增语音消息**，选择发送者和时间。只填时长即可生成截图里的静态语音条。要给已有消息加附件，可展开 **逐条编辑消息与时间**。要一次插入多张图，可在 **整组附图**上传图片，再在脚本中写 `名字：[图片]`。想在输入框保留没发出去的话，可填写 **未发送草稿**。

![完整聊天截图编辑器](previews/editor-chat.png)

## 3. 制作社交动态和论坛截图

1. 在 **截图创作**中选择 Instagram、X 或 theqoo。
2. 填写账号、正文、发布时间、评论等内容；theqoo 还可填写版面、分类和帖子标题。
3. 评论可使用 `用户名：评论内容` 快速录入。X 和 theqoo 的新评论行开头可按 Tab 或加两个空格，回复上方最近一条主评论。空行和没有用户名的续行仍属同一条评论。也可在逐条编辑区设置账号、头像和回复，头像可从顶部「素材库」选用。theqoo 的回复显示楼号引用。
4. 上传需要的头像或帖子图片，确认预览后导出 PNG。

各模板分别保留内容；同一模板的内容也可用于交互手机。

![Instagram 帖子编辑器](previews/editor-instagram.png)

## 4. 制作交互手机

1. 点工具栏的 **新建交互手机**，选择 **自由探索** 或 **剧情探索**。自由探索默认关闭剧情流程。可在工作台顶部的 **阅读方式** 切换，已有剧情步骤会保留。在 **手机外观** 中设置手机主人、机型、锁屏介绍和壁纸。
2. 在 **桌面应用**中配置图标、名称、语言、Dock 和应用页码。两页可左右滑动；**首页小组件**可添加时间日期与地点、4×2 备忘录或 2×2 相册预览。
3. 在 **应用内容**中展开对应 App，编辑聊天、社交动态、通话和日历内容。
4. 在 **相册与备忘录**中加入照片和备忘录。多篇备忘录显示列表，只有一篇时直接进入该篇。
5. 在 **剧情触发**中设置连续步骤。
6. 使用右侧手机试玩；点击 **重新试玩**可清除本次试玩进度。
7. 完成后点击 **导出可交互作品 HTML**。

应用状态：

| 设置 | 效果 |
|---|---|
| 启用此应用 | 应用参加作品，按设置显示在桌面或 Dock |
| 关闭“启用此应用” | 应用不参加作品，入口隐藏；截图模板仍可单独使用 |
| 开始时锁定 | 应用参加作品，但等待剧情中的“解锁应用”结果后才出现 |

![桌面应用设置](previews/editor-apps.png)

在 **交互手机 → 手机外观 → 工程基础设置 → 画布设置**可以选择仅显示屏幕，并调整机型和壁纸。**锁屏设置**里可选择从锁屏或桌面开始，并设置开场通知和 4 或 6 位数字密码。读者用数字键盘解锁。在 **剧情触发**中可指定接收会话、设置延时撤回、预写回复和提示语言。

如果想沿用手机外观开启新故事，选择 **从当前设置新建空白作品**。当前工程会先保存到工程库。

通话和日历每行填一条。需要注明日期时，在行首加 `YYYY-MM-DD ·`，例如 `2026-06-07 · Sana · 22:48 · 未接来电` 或 `2026-06-08 · 09:00 · 舞蹈练习`。日历可指定打开日期，读者可切换日期和月份。

上传了音频的语音消息可由读者点击语音条左侧的播放键播放。只填时长时，互动作品和截图都显示静态语音条。

## 5. 设置连续剧情和分支

全作品最多 **99 步**，所有分支共用这个额度。每步最多 **3 个结果**。超过 20 步后，可用 **步骤范围** 切换编辑。

1. 在 **剧情触发**中添加步骤，填写步骤名称。
2. 选择 **触发行为**和**指定内容**，例如查看某张照片或打开某篇备忘录。
3. 按需设置延迟和额外前置线索；两条线索可选择“全部满足”或“任意一条满足”。
4. 在 **接下来发生**中添加结果。
5. 若添加“让读者作出选择”，填写两个选项，并指定各自进入的后续步骤。
6. 在右侧试玩，展开 **剧情试玩记录**，检查当前等待项和已触发事件。

| 配置 | 支持内容 |
|---|---|
| 触发行为 | 打开作品、查看照片、打开备忘录、进入聊天、打开帖子详情、点赞指定帖子、查看通话详情、打开应用、发送预写回复 |
| 额外线索 | 最多两条，全部满足或任意一条满足 |
| 延迟 | 0–60 秒 |
| 后续结果 | 追加消息、新增备忘录、解锁应用、读者选择、显示结局 |
| 选择分支 | 两个选项，可向后跳转到指定步骤或结束故事 |

后续步骤会等待新的读者行为。修改工程会重置编辑器中的试玩进度。

可以点击 **载入 13 步示例**学习配置；载入前请先导出自己的工程备份。

## 6. 保存、备份和继续编辑

- 编辑器自动保存到当前浏览器，可在工程库另存多个副本，并保留最近一次保存前的恢复副本；本机副本不能替代 JSON 备份。
- 点击顶部 **导出工程**，保存 JSON 文件，作为可继续编辑的备份。
- 点击 **导入工程**，恢复已有 JSON 工程。
- 多个作品请分别导出；换设备、换浏览器、清理浏览器数据或更换网站地址前，也请先备份。
- PNG 是图片成品；HTML 是互动作品成品；需要继续编辑时，应使用 JSON 工程备份。

草稿不会自动上传到 GitHub 或云端。导出的读者作品可在允许本机存储的浏览器中恢复阅读进度。

## 7. 把作品分享给读者

**截图作品：**导出 PNG 后，可直接发送图片或发布到社交平台。

**交互作品：**导出 HTML 后，可发送文件，或将文件放到静态网站，生成读者能直接打开的网页链接。手机打开本地 HTML 的方式随浏览器不同，发布前请实机验证。

**邀请码发布：**站点启用发布服务后，在交互手机点 **发布到 FicPhone**，填写邀请码、作品名、作者署名和可选简介。勾选 **列入作品区** 后会公开展示。未列出的作品仍可通过阅读链接打开。发布数据上限为 5 MiB。没有邀请码时，可查看站内 **使用指南 → 把作品分享给读者**，按步骤自行托管导出的 HTML。

## 9. 相册、字体与署名

- 在 **交互手机 → 相册与备忘录** 上传照片，再点 **新建相册**，填写名称并勾选照片。同一照片可加入多个相册；删除相册只删除分组。
- **作品字体**提供系统默认、衬线、等宽，以及 Jua、Gamja Flower、Yomogi、站酷快乐体。混合语言使用备用字体补足；生僻字可能回退到系统字体。字号可自设 7–30 pt，正文、评论、联系人备注和账号名称同步缩放。可导入 WOFF2，也可选择将字体嵌入互动 HTML。
- 如需署名，填写 **作者署名**，再分别勾选截图水印或互动 HTML 作者署名。两个选项默认关闭。
- 底部 **隐私与数据**说明本机保存范围与备份方式；**版权与素材**列出工具和第三方素材说明。

## 当前功能范围

- 每个平台最多 50 个会话／帖子；群聊含主人和对方最多 9 人。theqoo 分类栏暂为展示。
- 每个截图稿可独立编辑时间与内容，可按分组或选择的稿件导出 ZIP。每条内容最多 9 张附图。
- 分支只能向后跳转。进入指定内容即触发，不自动识别是否读完全文。
- 暂不支持自由变量、多章节工程、云同步和多人协作。锁屏密码是剧情道具。

素材与依赖说明：[人物照片](DEMO-MEDIA-SOURCES.json) · [画布规格](DEVICE-SOURCES.md) · [应用图标](ICON-SOURCES.json)。html2canvas 许可文件保留在 docs/vendor/。

## 常用操作速查

- 截图稿可复制、重命名和分组。在对话或帖子编辑区顶部切换稿件，展开「管理截图稿」调整顺序或选择导出。
- 会话／帖子：在下拉框中切换，复制创建新项。群聊成员姓名应与脚本发送者一致。
- 逐条编辑：展开面板填写独立时间；脚本写法是 `姓名：[23:08] 消息`。
- 多图：多选上传、逐张移除；聊天使用 `[图片]` 插入整组，社媒可横向滑动。
- 未读：默认只标记最后一次对方回复后的我的消息；未读起点大于 0 时手动覆盖，序号包含全部消息。
- 提示：作者填写两级提示，读者主动点击后展开；初次打开和重新开始均折叠。
- 署名：截图水印与 HTML 作者署名分别开启，默认关闭。
- 保存：顶部显示状态；工程库另存副本；跨设备仍导出／导入 JSON。
- 撤销／重做：编辑区提供操作按钮和「清空模板示例」。清空仅作用于当前编辑的会话或帖子，可撤销。输入框外可用 ⌘/Ctrl+Z 撤销、⌘/Ctrl+Shift+Z 或 Ctrl+Y 重做，重做需确认。
- 版本日志：点击编辑器页脚的版本号查看。
